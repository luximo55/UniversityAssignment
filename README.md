# UniversityAssignment
My first game made in raylib using C++!
This game is a submission for the CGMT Bachelor for programming at BUas

## Story
You play as Charlie, the ghost who haunts the house of a kind family. Charlie is a kind ghost and helps the family.
One night family's parents went out, and the teens had a party and, of course, made a mess.
Your task is to help the teens clean up before the parents arrive (indicated by the car and the timer in the top-left corner).

## Controls
Arrow keys - Movement <br>
Space - Transform in/out <br>
Esc - Quit
